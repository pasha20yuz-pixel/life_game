# Game of Life — Conway's Game with Barriers

Игра «Жизнь» Конвея на языке C (графика — [raylib](https://www.raylib.com/)) с двумя режимами:

- **Classic** — свободное поле, рисование клеток мышью, готовые паттерны (случайный, глайдер, блинкер).
- **Campaign** — 10 уровней с **барьерами** между соседними клетками. Нужно расставить стартовые клетки так, чтобы к целевому поколению оставалось не менее 4 живых клеток.

Курсовая работа по дисциплине «Оптимизация программ», СПбПУ, 2026.
Авторы: Южалкин П. А., Дубицкий Д. А.

> Репозиторий содержит **базовую (неоптимизированную) версию** — она используется как точка отсчёта
> для профилирования и последующих оптимизаций. Тег `baseline` указывает на этот коммит.

## Сборка (Windows, MinGW-w64 + raylib)

Предполагается, что raylib установлен в `C:\raylib`.

```powershell
$env:PATH = "C:\raylib\lib;$env:PATH"
gcc -std=c99 -D_WIN32_WINNT=0x0601 `
  -I"C:/raylib/include" -L"C:/raylib/lib" `
  src/main_raylib.c src/patterns.c src/file_io.c `
  src/world.c src/barriers.c src/levels.c `
  -lraylib -lopengl32 -lgdi32 -lwinmm -lm `
  -o game.exe
```

Запуск:

```powershell
.\game.exe            # игра
.\game.exe --help     # справка
.\game.exe --version  # версия
```

Игру нужно запускать из корня репозитория: уровни читаются из `levels/`, а лог и прогресс пишутся в `game.log` и `progress.dat` (они в `.gitignore`).

## Управление

| Действие | Classic | Campaign |
|---|---|---|
| Пауза / продолжить | `Space` | `Space` или кнопка Run/Pause |
| Один шаг | `Enter` (на паузе) | `Enter` или кнопка Step |
| Скорость | `+` / `-` | `+` / `-` |
| Сетка | `G` | `G` |
| Паттерны | `F1` случайный, `F2` глайдер, `F3` блинкер | — |
| Поставить / убрать клетку | ЛКМ / ПКМ | ЛКМ / ПКМ (фаза расстановки) |
| Отмена шага | — | `Ctrl+Z` |
| Сброс уровня | `C` — очистить | `R` или кнопка Reset |

В кампании кнопка **Auto Solve** подбирает стартовую расстановку (устойчивый блок 2×2), проверяя её настоящей симуляцией с барьерами.

## Формат файла уровня (`levels/levelN.txt`)

```
W H                     размеры поля
MAX_START TARGET_GEN    максимум стартовых клеток, целевое поколение
H строк по (W-1) символов   барьеры между (y,x) и (y,x+1): 1 — барьер есть
H-1 строк по W символов     барьеры между (y,x) и (y+1,x): 1 — барьер есть
описание уровня
```

Барьер блокирует связь между двумя соседними по стороне клетками; диагональные соседи барьерами не блокируются.

## Структура проекта

```
src/
  main_raylib.c   главный цикл, интерфейс, режимы Classic и Campaign, история ходов
  world.c/.h      правила Конвея (с барьерами и без)
  barriers.c/.h   хранение барьеров
  levels.c/.h     загрузка уровней
  patterns.c/.h   готовые паттерны
  file_io.c/.h    работа с файлами
levels/           level1.txt … level10.txt
```

## План оптимизации (курсовая)

1. **Профилирование** базовой версии (gprof / замеры времени на фиксированных входных данных), оценка алгоритмической сложности.
2. **Алгоритмическая оптимизация** — см. отчёт.
3. **Не менее двух машинно-независимых оптимизаций** — каждая отдельным коммитом.
4. Повторное профилирование после каждого шага, графики и итоговая оценка сложности — в отчёте.

История коммитов отражает порядок оптимизаций.
